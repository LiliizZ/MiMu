# Dataset
We use datasets as follows:
- MNLI with dev-match and dev-mismatch [website](https://cims.nyu.edu/~sbowman/multinli/), Hans (OOD) [website](https://github.com/tommccoy1/hans), 
- QQP [website](https://quoradata.quora.com/First-Quora-Dataset-Release-Question-Pairs), PAWS (OOD) [website](https://github.com/google-research-datasets/paws)

- Imagenet-200 [website](https://scidata.sjtu.edu.cn/records/tmy1y-p8f67), Imagenet-R (OOD) [website](https://github.com/hendrycks/imagenet-r)

- Imagenet-9 and Mixed-Same, Mixed-Rand (OOD) [website](https://github.com/MadryLab/backgrounds_challenge)

- IN-9-W and IN-200-W can be obtained by watermark.py
